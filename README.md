# RTK Skills — ECI Distribution

Enterprise skills and rules for adopting [RTK (Rust Token Killer)](https://www.rtk-ai.app/) — cuts AI-agent token consumption 60–90% on CLI command output.

## Package layout

```
rtk-skills/
├── .claude/skills/              # Claude Code skills (copy into repo or ~/.claude/skills/)
│   ├── rtk-adoption/
│   │   ├── SKILL.md
│   │   └── references/governance.md
│   └── rtk-operations/
│       └── SKILL.md
├── cursor-rtk/                  # Cursor rules bundle
│   ├── .cursor/rules/
│   │   ├── rtk.mdc              # always-on behavioral rule
│   │   └── rtk-operations.mdc   # agent-requested operations rule
│   └── README.md
├── examples/
│   └── filters.toml             # starter .rtk/filters.toml for product repos
├── dist/                        # portable .skill zips (generated by scripts/pack-skills.sh)
├── scripts/
│   ├── validate.sh              # pre-share smoke test
│   └── pack-skills.sh           # rebuild dist/*.skill from SKILL.md sources
└── README.md                    # this file
```

## Quick start

### 1. Validate the package (maintainers)

```bash
./scripts/validate.sh           # package structure only
./scripts/validate.sh --full    # also requires RTK installed
```

### 2. Adopt in a product repo

**Claude Code** — copy skills into the repo:

```bash
cp -R .claude/skills/rtk-adoption .claude/skills/rtk-operations /path/to/repo/.claude/skills/
```

**Cursor** — copy rules into the repo:

```bash
cp -R cursor-rtk/.cursor /path/to/repo/
```

**Every developer, once per machine** — pick your platform:

| Platform | Install | Init — Claude Code | Init — Cursor | Config path |
| --- | --- | --- | --- | --- |
| **macOS** | `brew install rtk` | `rtk init --global` | `rtk init -g --agent cursor` | `~/Library/Application Support/rtk/config.toml` |
| **Linux / WSL** | [install.sh](https://raw.githubusercontent.com/rtk-ai/rtk/refs/heads/master/install.sh) | `rtk init --global` | `rtk init -g --agent cursor` | `~/.config/rtk/config.toml` |
| **Windows (WSL)** — recommended | install.sh inside WSL | `rtk init --global` from WSL | `rtk init -g --agent cursor` from WSL | `~/.config/rtk/config.toml` |
| **Windows (native)** | [GitHub release zip](https://github.com/rtk-ai/rtk/releases) | `rtk init --global` + explicit `rtk` prefixes | `rtk init -g --agent cursor` + explicit `rtk` prefixes | `%APPDATA%\rtk\config.toml` |

```bash
# macOS / Linux / WSL

# Install
brew install rtk                          # macOS
curl -fsSL https://raw.githubusercontent.com/rtk-ai/rtk/refs/heads/master/install.sh | sh  # Linux / WSL

rtk --version && rtk gain                 # verify correct package (not the crates.io collision)

# Init — pick ONE based on your AI tool
rtk init --global                         # Claude Code (ECI default)
rtk init -g --agent cursor                # Cursor

# restart your AI tool, then confirm savings are flowing
rtk gain                                  # savings counter should increment
```

```powershell
# Windows native (PowerShell)
# 1. Download rtk-x86_64-pc-windows-msvc.zip from https://github.com/rtk-ai/rtk/releases
#    Extract rtk.exe to a folder on PATH (e.g. $env:USERPROFILE\.local\bin)
# 2. rtk --version && rtk gain            # confirm correct package
# 3. rtk init --global                    # Claude Code
#    OR: rtk init -g --agent cursor       # Cursor
# 4. Restart your AI tool
#    Note: auto-hook requires WSL; on native Windows agents must prefix commands with rtk
```

**Global Claude Code install** (skills available across all repos — no per-repo copy needed):

```bash
cp -R .claude/skills/rtk-adoption .claude/skills/rtk-operations ~/.claude/skills/
```

Apply ECI governance defaults — see `.claude/skills/rtk-adoption/references/governance.md`.

**Windows full guide:** `.claude/skills/rtk-adoption/references/windows.md`

### 3. Optional repo-level filters

```bash
mkdir -p .rtk && cp examples/filters.toml .rtk/filters.toml
# customize for your toolchain, then commit
```

## Verify it works

| Check | Expected |
| --- | --- |
| `./scripts/validate.sh` | All package checks pass |
| `rtk --version` | `rtk 0.42.x` (not the wrong crates.io package) |
| `rtk init --show` | Hook installed for your agent |
| Agent runs `git status` | Compact output (~3 lines, not 40) |
| `rtk gain` | Non-zero savings after agent commands |
| Ask agent "RTK savings this week?" | Loads operations rule/skill, runs `rtk gain --weekly` |

## Distribution formats

| Format | Path | Use when |
| --- | --- | --- |
| Directory skills | `.claude/skills/rtk-*/` | Repo or global Claude Code install |
| Cursor rules | `cursor-rtk/.cursor/rules/` | Repo or Remote Rules (GitHub) |
| Portable zips | `dist/*.skill` | Share via Slack/email; import into Claude Code |

Regenerate portable zips after editing SKILL.md:

```bash
./scripts/pack-skills.sh
```

## Keeping artifacts in sync

When RTK behavior changes, update all three together:

1. `.claude/skills/rtk-adoption/SKILL.md` and `rtk-operations/SKILL.md`
2. `cursor-rtk/.cursor/rules/rtk.mdc` and `rtk-operations.mdc`
3. RTK Enterprise Adoption Guide (external)

Run `./scripts/validate.sh` before sharing with teams.

## Troubleshooting

See the `rtk-operations` skill/rule. Common issues:

- **Skills not loading** — ensure files are named `SKILL.md` (uppercase), not ZIP archives named `skill.md`.
- **No token savings** — RTK hook not installed; run `rtk init -g --agent cursor` and restart Cursor.
- **Windows native: no auto-filtering** — expected; use WSL for full hooks, or ensure `rtk.mdc` rules are committed and agent prefixes `rtk`.
- **Wrong `rtk` package** — `rtk gain` fails; uninstall the crates.io "Rust Type Kit" and reinstall from Homebrew or GitHub releases.
